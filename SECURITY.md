# Security

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** (Security → Advisories) instead of a public issue. You will get an acknowledgement within a few days. Only the latest release is supported.

## Threat model

| Threat                           | Mitigation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Test                                                          |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| API key theft                    | On Cloud Run, Vertex AI is called with the service account identity (Application Default Credentials) limited to `roles/aiplatform.user`; no key exists to leak. Config is validated at boot                                                                                                                                                                                                                                                                                                                           | `server/env.test.ts`, `server/providers.test.ts`              |
| Malformed or hostile input       | Strict Zod schemas on every request (unknown keys rejected), numeric ranges, 20 kB body cap                                                                                                                                                                                                                                                                                                                                                                                                                            | `server/app.test.ts`                                          |
| Server-side request forgery      | Live data is fetched only from one fixed host and only for cities on our own allow-list, with a 5 s timeout; the user supplies an id, never a URL                                                                                                                                                                                                                                                                                                                                                                      | `server/aqiProvider.test.ts`                                  |
| Prompt injection                 | The question is JSON-escaped inside `<user_input>` and treated as data; replies must match a strict schema and length cap and are rendered as plain text                                                                                                                                                                                                                                                                                                                                                               | `server/ai.test.ts`                                           |
| Unsafe health advice             | Emergency phrases are answered with a fixed safe message before any AI call; prompts forbid diagnoses and doses; babies are never told to wear masks                                                                                                                                                                                                                                                                                                                                                                   | `shared/ask.test.ts`, `server/app.test.ts`, `e2e/app.spec.ts` |
| Leaking family health details    | No accounts, no server-side storage. The household lives in the browser; the AI receives only a coarse, validated summary; request bodies are never logged                                                                                                                                                                                                                                                                                                                                                             | `shared/context.ts`, `server/log.ts`                          |
| Location privacy                 | Geolocation is allowed only for our own origin (`Permissions-Policy: geolocation=(self)`), requested only when the family taps the button, and turned into a city id in the browser. Coordinates are never sent or stored; a real-browser test asserts that no request contains them                                                                                                                                                                                                                                   | `e2e/app.spec.ts`, `client/locate.ts`                         |
| Slow or hung dependencies        | 10 s per AI attempt, 25 s deadline, 5 s for live air data; every failure has a fallback (rules, manual AQI)                                                                                                                                                                                                                                                                                                                                                                                                            | `server/ai.test.ts`, `server/aqiProvider.test.ts`             |
| Abuse and denial of service      | Rate limit on `/api` (429), body cap, 15-minute cache of live readings                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `server/app.test.ts`                                          |
| Information leakage              | Generic error bodies (no stacks or secrets); request IDs for log correlation; `X-Powered-By` removed                                                                                                                                                                                                                                                                                                                                                                                                                   | `server/app.test.ts`                                          |
| Cross-origin and browser attacks | CORS allow-list (off by default). **Strict CSP:** `default-src 'self'`, no inline scripts or styles, no `eval`, `frame-ancestors 'none'`, `object-src 'none'`, `connect-src 'self'`. Also `nosniff`, HSTS, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-origin`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-DNS-Prefetch-Control: off`, Permissions-Policy (incl. `interest-cohort=()`), and `Cache-Control: no-store` on the API. Zero CSP violations in a real browser | `server/app.test.ts`, `e2e/app.spec.ts`                       |
| Compromised CI dependency        | Every GitHub Action is pinned to a commit SHA and updated through Dependabot; workflows run with read-only permissions; CodeQL scans weekly; CI checks for leaked secrets (API key patterns) in every push                                                                                                                                                                                                                                                                                                             | `.github/workflows/`                                          |
| Vulnerable dependencies          | `npm audit --omit=dev` reports 0 advisories and CI fails on high severity (see the dev-tooling note in [docs/QUALITY.md](docs/QUALITY.md))                                                                                                                                                                                                                                                                                                                                                                             | `.github/workflows/ci.yml`                                    |

## OWASP Top 10 (2021) mapping

| Risk                                           | How AirWise addresses it                                                                                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A01 Broken access control                      | No accounts and no stored user data; the API only computes and reads. CORS is an allow-list                                                                          |
| A02 Cryptographic failures                     | No secrets in code or in the browser; `.env.example` contains only placeholders; TLS on Cloud Run, HSTS and `upgrade-insecure-requests`; nothing sensitive is stored |
| A03 Injection                                  | Strict Zod validation on every input; no database and no dynamic HTML (React escapes); AI prompts fence user text as data; CSP forbids inline script and `eval`      |
| A04 Insecure design                            | Threat model above; every dependency has a fallback; emergencies bypass the AI; outbound calls are allow-listed and time-boxed                                       |
| A05 Security misconfiguration                  | Strict CSP and helmet headers, no `X-Powered-By`, config validated at boot, least-privilege service account                                                          |
| A06 Vulnerable and outdated components         | `npm audit` clean for production, Dependabot, lockfile, CodeQL                                                                                                       |
| A07 Identification and authentication failures | Not applicable: there are no accounts, by design                                                                                                                     |
| A08 Software and data integrity failures       | GitHub Actions pinned to commit SHAs; third-party data (live air, AI, browser storage) is schema-validated before use                                                |
| A09 Logging and monitoring failures            | Structured JSON logs with request IDs and trace links; bodies and personal data are never logged; a deep health check proves the AI path                             |
| A10 Server-side request forgery                | One fixed host, only for allow-listed city ids; a test passes a URL as the city and asserts no request is made                                                       |

See also [docs/RESPONSIBLE-AI.md](docs/RESPONSIBLE-AI.md).
