# Responsible AI

| Risk                          | Safeguard                                                                                                                                                                                                                                                                                   | Evidence                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Medical emergencies           | Possible emergencies (chest pain, cannot breathe, blue lips, "सांस…") are caught **before** any AI call and always get the same safe message: call 112 or seek care                                                                                                                         | `shared/ask.ts`, `server/app.test.ts`, e2e |
| Medical advice                | Prompts forbid diagnoses, doses and treatments; every answer sits next to a disclaimer; babies under 2 are never advised to wear a mask                                                                                                                                                     | `server/ai.ts`, `shared/actions.ts`        |
| Made-up numbers               | The model only gets a small, validated context (AQI, level, top steps) and is told to use nothing else. All impact numbers come from the deterministic model, never from the AI                                                                                                             | `shared/context.ts`, `server/ai.test.ts`   |
| Prompt injection              | The question is JSON-escaped inside `<user_input>` and treated as data; replies must match a strict schema and a length cap, and are shown as plain text                                                                                                                                    | `server/ai.test.ts`                        |
| Over-reliance                 | Answers are labelled **AI answer** or **Rule-based answer**; if the AI is down the app says so and falls back to rules                                                                                                                                                                      | `client/components/Assistant.tsx`          |
| Privacy of health information | No accounts and no server storage. The household lives only in this browser. When you ask the AI, only a coarse summary is sent (city name, AQI, level, a list like "a baby under 2" and the top step titles), never counts or free text about your family; request bodies are never logged | `shared/context.ts`, `server/log.ts`       |
| Location privacy              | "Use my location" runs in the browser: the position is matched to the nearest listed city and then discarded. Only the city id is used afterwards; coordinates are never sent, stored or logged                                                                                             | `shared/cities.ts`, `e2e/app.spec.ts`      |
| Language access               | Briefings in English, Hindi and Marathi, marked with the right `lang` attribute for screen readers                                                                                                                                                                                          | `client/components/Assistant.tsx`          |
